# CookingGrenades — 温雷模组

> **版本**: 1.4.1  
> **适用**: SPT 4.1.0 / BepInEx 5.x / .NET Framework 4.7.2  
> **BEP插件ID**: `com.Tangh.CookingGrenades`

---

## 概述

CookingGrenades 为 SPT 添加了**手雷温雷（Cooking）**机制，让你可以像真实作战一样——拉开保险销后不立即扔出，而是握在手中计算时机，再在恰到好处的时刻投出，让敌人在空中或落地瞬间被引爆，没有反应时间。

同时提供了**手雷抛物线预测**和**温雷提示图标**等辅助功能，帮助你在激烈交火中精准掌控每一颗雷。

---

## 功能详情

### 1. 温雷（Cooking）核心机制

- **操作方式**：手持手雷状态下，按住鼠标左键（高抛）或右键（低抛）即可开始温雷
- **拔销检测**：系统会自动等待拔销动画完成后才开始计时，避免误判
- **自动投掷**：当温雷时间接近引信时间时，手雷会被强制投出，防止在手中爆炸
- **动作锁定**：温雷期间会禁用换武器、开门、捡拾物品等操作，确保不会意外打断温雷流程

### 2. 真实引信时间（Realistic Fuse Time）

为手雷引信时间引入**随机波动**，每颗雷的引信时间都不完全相同，模拟真实军火的制造公差：

- **开启/关闭**：可在 F12 配置菜单中开关
- **波动幅度控制**（`Fuse Time Spread Factor`）：范围 0.001 ~ 0.6
  - 0.001 ≈ 固定引信时间（几乎无波动）
  - 0.6 ≈ 较大范围波动
- **库存界面**：可选择在物品栏中显示默认引信时间还是随机值

> 引信时间使用正态分布（Box-Muller 算法）生成，大多数雷的引信时间集中在平均值附近，少数会有较大偏差，更贴近真实。

### 3. 引信时间模拟器（Fuse Time Tester）

内置的测试工具，帮助你调整到满意的引信波动范围：

- **目标值**（`Simulation Target Value`）：设定你想测试的基准引信秒数
- **测试次数**（`Fuse Time Test Count`）：每次模拟的采样数量（1 ~ 100,000）
- **输出开关**（`Time Simulation To Output`）：设为 `true` 触发一次模拟，结果输出到 `BepInEx/LogOutput.log`

日志会给出最小值、最大值、平均值、标准差，以及每个时间值的频次分布表，方便你精确调参。

### 4. 手雷抛物线预测（Trajectory Prediction）

手持手雷准备投掷时，显示一条**飞行轨迹线**和一个**落点标记**：

- **显示模式**：
  - 模式 0：手持手雷时始终显示
  - 模式 1：仅在高抛/低抛瞄准时显示
- **物理模型**：含线性阻力的弹道解析解，考虑以下因素：
  - 手雷质量（从 Rigidbody 动态读取）
  - 玩家当前移动速度
  - 力量技能等级与手耐力
  - 高抛/低抛倍率差异
- **碰撞检测**：轨迹线会与场景碰撞，终点显示落点标记
- **可选配置**：
  - 轨迹线颜色、落点颜色
  - 轨迹线宽、落点半径
  - 采样点数与步长时间（影响平滑度和性能）
  - 投掷力度倍率（`Throw Force Multiplier`）：当预测落点与实际落点有偏差时微调

### 5. 温雷提示图标（Cook Indicator）

温雷时屏幕上的闪烁提示，让你**不盯着手雷也能感知剩余时间**：

- **位置**：屏幕中心偏移位置（可配置 X/Y 偏移）
- **闪烁节奏**：
  - 剩余时间 > 2 秒：黄色慢闪，随烹饪时间加快闪烁频率
  - 剩余时间 ≤ 2 秒：红色快闪，频率极高，提示即将爆炸
- **投掷动画**：扔出时图标会逆时针旋转 45° 并淡出消失
- **自定义**：可调节图标大小、高度、屏幕偏移量

### 6. 音效优化

- **拔销音效替代**：对 M67、V40、M18 烟雾、M7290 闪光、RDG-2B 等手雷，使用更合适的 `TripwirePin` 音效替代默认的引信音效
- **引信音效屏蔽**：温雷时自动屏蔽默认的引信嘶嘶声，避免音效重叠

### 7. 安全警告

首次安装进入主菜单时，会弹出**安全警告**，提醒温雷在现实中的极度危险性，确认后不再显示。

### 8. 手雷轮盘（Grenade Wheel）

按住默认的 **G 键**（可在 F12 配置中修改）在屏幕中心打开一个**手雷轮盘**，直观地显示背包中所有手雷：

- **操作方式**：在战斗中按住按键 → 屏幕中心弹出轮盘 → 移动鼠标选择手雷 → 松键自动装备
- **视觉反馈**：轮盘呈圆形排列，每个手雷用不同颜色区分类型，选中高亮为金黄色
- **光标控制**：轮盘打开时会自动释放鼠标光标，方便精准选择；关闭后自动恢复锁定
- **装备扫描**：自动扫描**战术弹挂**和**口袋**中的手雷；**背包**默认不扫描（可在 F12 配置中开启）
- **设备行为**：可配置"选中后立即装备"与"手持时立即切换"，也可关闭它们改为仅设置偏好手雷（再按一次键掏出）
- **安全保护**：温雷期间不会触发轮盘；轮盘打开期间无法开枪、瞄准、切换武器
- **配置开关**：可在 F12 配置菜单中完全禁用（默认开启）

### 9. 医药轮盘（Medicine Wheel）

复用**手雷轮盘**的轮盘 UI 效果，长按按键唤出**医药轮盘**，鼠标选择药品，松开即直接使用：

- **操作方式**：按住默认的 **H 键**（可在 F12 配置中修改）→ 屏幕中心弹出轮盘 → 移动鼠标选择药品 → 松开自动使用
- **药品扫描**：
  - 默认扫描**战术弹挂**与**口袋**中的药品；**背包**默认不扫描（可在 F12 配置中开启）
  - **安全箱**（Kappa/Alpha 箱）默认开启扫描（可在 F12 配置中关闭）
  - 食物与饮水默认一并显示（可在 F12 配置中关闭）
- **药品分类配色**：急救包=绿色、药品/兴奋剂/止痛药=紫色、食物饮水=橙色、其他医疗用品（绷带/手术包等）=蓝色
- **使用方式**：选择后直接走游戏原生用药流程（`Proceed`），医疗品与食物饮水均可直接使用
- **互斥保护**：与手雷轮盘互斥，同一时间只能打开一个；温雷期间不会触发
- **输入保护**：轮盘打开期间屏蔽游戏输入，防止移动/开枪/切枪干扰选择
- **配置开关**：可在 F12 配置菜单中完全禁用（默认开启）

## 配置项一览

所有配置项均可在 F12 配置菜单中调整，按分类整理如下：

### 0. 温雷（Cooking Grenades）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `Enable Cooking Notification` | bool | `false` | 开始温雷时显示通知消息 |
| `Auto Throw Lead Time` | float | `0.8` | 距离引信爆炸剩余多少秒时强制投出（0.1 ~ 3，越大越早投出越安全） |
| `Show Default Fuse Time In Inventory UI` | bool | `true` | 库存界面显示默认引信时间（而非随机值） |
| `Use Alternative Pin Sound` | bool | `true` | 对特定手雷使用替代拔销音效 |

### 1. 真实引信时间（Realistic Fuse Time）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `Realistic Fuse Time Enable` | bool | `false` | 启用引信时间随机波动 |
| `Fuse Time Spread Factor` | float | `0.085` | 波动幅度（0.001 ~ 0.6），越大波动范围越宽 |

### 2. 引信时间模拟器（Realistic Fuse Iime Tester）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `Simulation Target Value` | float | `5.0` | 模拟基准值（秒） |
| `Fuse Time Test Count` | int | `10000` | 每次模拟采样数 |
| `Time Simulation To Output` | bool | `false` | 设为 `true` 触发一次模拟并输出结果到日志 |

### 3. 调试（Debug）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `Enable Cooking Time GUI` | bool | `false` | 启用调试 GUI，显示温雷计时信息 |
| `User Warning Confirmed` | bool | `false` | 是否已确认安全警告（高级选项） |

### 4. 抛物线预测（Trajectory Prediction）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `Enable Trajectory` | bool | `true` | 启用抛物线预测 |
| `Display Mode` | int | `0` | 显示模式：0=手持即显示，1=仅投掷瞄准时显示 |
| `Trajectory Color` | Color | `(1,0.3,0.1,0.8)` | 轨迹线颜色（RGBA） |
| `Landing Point Color` | Color | `(1,0,0,0.9)` | 落点标记颜色（RGBA） |
| `Landing Point Radius` | float | `0.3` | 落点标记半径（米，范围 0.05 ~ 2） |
| `Trajectory Points` | int | `60` | 轨迹采样点数（10 ~ 200，越多越平滑但越耗性能） |
| `Trajectory Step Size` | float | `0.5` | 相邻采样点水平间距（米，范围 0.1 ~ 2），越小越密集越平滑 |
| `Trajectory Line Width` | float | `0.015` | 轨迹线宽（范围 0.005 ~ 0.1，实际渲染会放大） |
| `Throw Force Multiplier` | float | `1.0` | 投掷力度倍率（0.5 ~ 3），预测落点不准时微调 |
| `Recalc Interval (frames)` | int | `2` | 投掷参数不变时每 N 帧重算一次抛物线（1=每帧，越大越省性能但反应越慢） |

### 5. 温雷提示（Cook Indicator）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `Enable Cook Indicator` | bool | `true` | 启用温雷提示图标 |
| `Indicator Height` | float | `1.0` | 图标在屏幕上方基准高度（米，范围 0.1 ~ 2） |
| `Indicator Scale` | float | `0.15` | 图标缩放大小（范围 0.05 ~ 1） |
| `Offset X (px)` | float | `200` | 屏幕中心水平偏移像素（-500 ~ 500，正=向右） |
| `Offset Y (px)` | float | `0` | 屏幕中心垂直偏移像素（-500 ~ 500，正=向上） |
| `Throw Animation Duration (s)` | float | `2.5` | 扔雷时图标旋转淡出动画时长（秒，范围 0.1 ~ 5） |

### 6. 手雷轮盘（Grenade Wheel）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `Enable Grenade Wheel` | bool | `true` | 启用手雷轮盘选择器（按住按键打开） |
| `Grenade Wheel Key` | KeyCode | `G` | 长按唤出到手雷轮盘的按键 |
| `Equip Immediately On Select` | bool | `true` | 松键时立即装备选中的手雷；关闭则仅设为偏好手雷（需再按一次键掏出） |
| `Switch Immediately When Holding` | bool | `true` | 若已手持手雷，选中不同手雷时立即切换；关闭则仅设置偏好不立即切换 |

### 7. 医药轮盘（Medicine Wheel）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `Enable Medicine Wheel` | bool | `true` | 启用医药轮盘选择器（按住按键打开） |
| `Medicine Wheel Key` | KeyCode | `H` | 长按唤出医药轮盘的按键 |
| `Scan Secure Container For Medicine` | bool | `false` | 是否扫描安全箱中的药品 |
| `Scan Backpack For Medicine` | bool | `false` | 是否扫描背包中的药品（默认只扫描口袋和战术弹挂） |
| `Include Food And Drinks` | bool | `true` | 是否在医药轮盘中显示食物与饮水 |

## 操作方法

| 操作 | 按键 | 说明 |
|------|------|------|
| 高抛温雷 | 按住 **鼠标左键** | 拔销后开始温雷，松开即高抛投出 |
| 低抛温雷 | 按住 **鼠标右键** | 拔销后开始温雷，松开即低抛滚出 |
| 强制投出 | 自动 | 温雷时间接近引信时自动投出，防止手里爆炸 |
| 打开手雷轮盘 | 按住 **G** | 按住 G 显示手雷轮盘，移动鼠标选择，松开装备 |
| 打开医药轮盘 | 按住 **H**（可改） | 按住显示医药轮盘，移动鼠标选择药品，松开直接使用 |

> **提示**：温雷期间无法进行换武器、开门、交互等操作，这是为了防止误操作打断温雷。

## 兼容性

- 最低要求：SPT 4.1.0 / BepInEx 5.x / .NET Framework 4.7.2
- 每个 Patch 独立 try-catch，单个功能失败不会导致整个模组崩溃
- 保留了对旧版 `Cook(float, bool)` 的兼容逻辑
